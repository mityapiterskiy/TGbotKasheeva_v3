# Инструкция по настройке и запуску бота

## Шаг 1: Создание бота в Telegram

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Терапевтический бот Кащеевой")
   - Введите username бота (должен заканчиваться на `bot`, например: `kashcheeva_therapy_bot`)
4. Сохраните токен бота (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Настройка переменных окружения

1. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и заполните:
   - `BOT_TOKEN` - токен от BotFather
   - `MODERATOR_ID` - ваш Telegram ID (узнайте у [@userinfobot](https://t.me/userinfobot))
   - `CHANNEL_USERNAME` - username вашего канала (без символа @)
   - `EMAIL_TO` - email для получения Excel файлов (опционально)
   - `SMTP_*` - настройки для отправки email (опционально)

## Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 4: Загрузка видео-уроков

1. Запустите скрипт для получения file_id:
   ```bash
   python get_video_id.py
   ```

2. Отправьте каждое видео боту в личные сообщения (по одному за раз)

3. Скопируйте полученные file_id

4. Откройте `bot_structure.json` и замените:
   - `VIDEO_LESSON_1_FILE_ID` на file_id первого видео
   - `VIDEO_LESSON_2_FILE_ID` на file_id второго видео
   - `VIDEO_LESSON_3_FILE_ID` на file_id третьего видео

Пример:
```json
{
  "id": 1,
  "video_file_id": "BAACAgIAAxkBAAIBY2Z..."  // Вставьте реальный file_id
}
```

## Шаг 5: Запуск бота

```bash
python bot.py
```

Бот должен ответить: "Бот запущен!"

## Шаг 6: Тестирование

1. Найдите вашего бота в Telegram по username
2. Отправьте команду `/start`
3. Пройдите весь опрос
4. Проверьте:
   - Получение видео-уроков
   - Сохранение ответов в Excel (папка `responses/`)
   - Отправку сообщения модератору (если настроено)

## Структура опроса

1. **Проверка подписки** - пользователь должен подписаться на канал
2. **Вопрос 1**: С какой сферой сейчас труднее всего справляться?
   - Варианты: отношения к еде, деньги, уверенность, отношения, привычки
3. **Вопрос 2**: Когда вам становится тяжело, вы обычно ищете поддержку?
   - Варианты: держу в себе, обсуждаю с близкими, обращаюсь к специалисту
4. **Вопрос 3**: Как вы относитесь к идее пройти терапевтическую группу?
   - Варианты: хочу начать, думаю но откладываю, интересно но нет уверенности
5. **Уроки** - показываются 3 видео-урока последовательно
6. **Результат** - определяется группа и отправляется финальное сообщение

## Определение группы

Группа определяется автоматически на основе первого ответа:

- **Группа 15** - если ответ про еду/тело
- **Группа 16** - если ответ про деньги/финансы
- **Группа 17** - если ответ про уверенность/самооценку
- **Группа 18** - если ответ про отношения
- **Группа 19** - если ответ про привычки/зависимости

## Отправка результатов

Результаты сохраняются в Excel файл (`responses/responses_YYYYMMDD.xlsx`) и:
- Отправляются на email (если настроен SMTP)
- Отправляются модератору в Telegram (если указан MODERATOR_ID)

## Решение проблем

### Бот не отвечает
- Проверьте правильность токена в `.env`
- Убедитесь что бот запущен (`python bot.py`)
- Проверьте логи на наличие ошибок

### Видео не отправляется
- Убедитесь что file_id правильный (проверьте через `get_video_id.py`)
- Проверьте что видео загружено в Telegram (не ссылка на YouTube)

### Email не отправляется
- Проверьте настройки SMTP в `.env`
- Для Gmail используйте "Пароль приложения" вместо обычного пароля
- Проверьте что порт 587 не заблокирован файрволом

### Excel файл не создается
- Убедитесь что папка `responses/` существует или будет создана автоматически
- Проверьте права на запись в директорию проекта

## Дополнительная настройка

### Изменение текстов сообщений

Отредактируйте файл `bot_structure.json`:
- `greeting` - приветственное сообщение
- `questions` - вопросы и варианты ответов
- `lessons` - описания уроков
- `groups` - названия и описания групп

### Добавление новых вопросов

В `bot_structure.json` добавьте новый объект в массив `questions`:
```json
{
  "id": 4,
  "text": "Ваш вопрос?",
  "variants": ["Вариант 1", "Вариант 2"],
  "next_question": null,
  "next_step": "lessons"
}
```

## Поддержка

При возникновении проблем проверьте логи бота и убедитесь что все настройки корректны.
