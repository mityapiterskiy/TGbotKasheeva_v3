# Как запустить бота

## ❌ Неправильный способ (что вы делали):

```python
python3
>>> bot.py  # ❌ Это не работает!
```

## ✅ Правильный способ:

### Шаг 1: Выйдите из Python интерактивного режима

Если вы в Python интерактивном режиме (видите `>>>`), выйдите:
```python
exit()
# или нажмите Ctrl+D
```

### Шаг 2: Установите зависимости (если еще не установлены)

```bash
pip3 install -r requirements.txt
```

### Шаг 3: Запустите бота

```bash
python3 bot.py
```

Или просто:

```bash
python bot.py
```

## 📋 Полная последовательность команд:

```bash
# 1. Перейдите в папку проекта
cd /Users/mitya/CursorAI/TGbotKasheeva_v3

# 2. Установите зависимости (один раз)
pip3 install -r requirements.txt

# 3. Убедитесь что .env файл заполнен
# Откройте .env и заполните BOT_TOKEN

# 4. Запустите бота
python3 bot.py
```

## ✅ Что вы должны увидеть:

Если все правильно настроено:
```
Бот запущен!
```

Если есть ошибки:
- Проверьте что `BOT_TOKEN` заполнен в `.env`
- Проверьте что все зависимости установлены
- Проверьте что файл `bot_structure.json` существует

## 🔍 Проверка перед запуском:

```bash
# Проверьте что токен есть
grep BOT_TOKEN .env

# Проверьте что зависимости установлены
pip3 list | grep aiogram

# Проверьте что файлы на месте
ls -la bot.py config.py utils.py
```

## ⚠️ Частые ошибки:

1. **"BOT_TOKEN не установлен"**
   - Откройте `.env` и заполните `BOT_TOKEN=ваш_токен`

2. **"ModuleNotFoundError: No module named 'aiogram'"**
   - Установите зависимости: `pip3 install -r requirements.txt`

3. **"FileNotFoundError: bot_structure.json"**
   - Убедитесь что файл существует в папке проекта

## 🛑 Остановка бота:

Нажмите `Ctrl+C` в терминале где запущен бот.
