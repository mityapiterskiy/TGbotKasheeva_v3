# Telegram Бот для психотерапевтической программы

Бот для проведения опроса пользователей и определения подходящей терапевтической группы.

## Функционал

- ✅ Проверка подписки на Telegram канал
- ✅ Интерактивный опрос с вариантами ответов
- ✅ Автоматическое определение группы на основе ответов
- ✅ Отправка видео-уроков (хранятся на серверах Telegram)
- ✅ Сохранение ответов в Excel файл
- ✅ Отправка результатов на email модератору
- ✅ Отправка результатов модератору в Telegram

## Установка

1. Клонируйте репозиторий или скачайте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env` файл:
   - `BOT_TOKEN` - токен бота от @BotFather
   - `MODERATOR_ID` - ваш Telegram ID (можно узнать у @userinfobot)
   - `EMAIL_TO` - email для получения Excel файлов (опционально)
   - `SMTP_*` - настройки SMTP для отправки email (опционально)
   - `CHANNEL_USERNAME` - username канала для проверки подписки (без @)

## Настройка видео-уроков

1. Загрузите видео-файлы в бота:
   - Отправьте видео боту в личные сообщения
   - Получите `file_id` из ответа бота или через API

2. Обновите `bot_structure.json`:
   - Найдите поле `video_file_id` для каждого урока
   - Замените `VIDEO_LESSON_1_FILE_ID` на реальный `file_id`

Пример:
```json
{
  "id": 1,
  "video_file_id": "BAACAgIAAxkBAAIBY2Z..." // Реальный file_id
}
```

## Логика определения группы

Бот определяет группу на основе первого ответа пользователя:

- **Группа 15 (Строимость)**: ответы про еду, тело, переедание, диеты
- **Группа 16 (Финансы)**: ответы про деньги, финансы, стабильность
- **Группа 17 (Самооценка)**: ответы про уверенность, самооценку, сомнения
- **Группа 18 (Отношения)**: ответы про отношения, близких, доверие
- **Группа 19 (Негативные привычки)**: ответы про привычки, зависимости

## Отправка результатов

Результаты отправляются двумя способами:

1. **Excel файл на email** (если настроен SMTP)
   - Файл создается в папке `responses/`
   - Отправляется на указанный email

2. **Сообщение модератору в Telegram**
   - Отправляется в личные сообщения модератору
   - Содержит все ответы пользователя и определенную группу

## Разработка

Для изменения структуры бота отредактируйте файл `bot_structure.json`:

- `greeting` - приветственное сообщение
- `questions` - массив вопросов с вариантами ответов
- `lessons` - массив уроков с видео
- `groups` - массив групп с описаниями

## Поддержка

- Наличие всех зависимостей
