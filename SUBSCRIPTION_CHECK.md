# Проверка подписки на канал @doctor_kashcheeva

## Как работает проверка подписки

Бот использует Telegram Bot API метод `getChatMember` для проверки статуса пользователя в канале. 

### Механизм проверки:

1. **При команде /start** бот проверяет, подписан ли пользователь на канал `@doctor_kashcheeva`
2. Если пользователь **НЕ подписан**:
   - Показывается сообщение с предложением подписаться
   - Отображается кнопка "Подписаться" со ссылкой на канал
   - Кнопка "✅ Я подписался" для повторной проверки
3. Если пользователь **подписан**:
   - Показывается кнопка "Начать диалогику"
   - Пользователь может начать опрос

### Требования для работы проверки:

⚠️ **ВАЖНО**: Для того чтобы бот мог проверять подписку на канал, необходимо:

1. **Бот должен быть администратором канала** `@doctor_kashcheeva`
   - Зайдите в настройки канала
   - Перейдите в "Администраторы"
   - Добавьте вашего бота как администратора
   - Можно дать только права на чтение сообщений (не обязательно публиковать)

2. **ИЛИ канал должен быть публичным**
   - Если канал приватный, бот обязательно должен быть администратором

### Настройка в .env файле:

```env
CHANNEL_USERNAME=doctor_kashcheeva
```

**Важно**: Указывайте username канала БЕЗ символа @

### Статусы подписки:

Бот проверяет следующие статусы пользователя:
- ✅ `MEMBER` - обычный подписчик (разрешено)
- ✅ `ADMINISTRATOR` - администратор канала (разрешено)
- ✅ `CREATOR` - создатель канала (разрешено)
- ❌ `LEFT` - пользователь покинул канал (не разрешено)
- ❌ `KICKED` - пользователь заблокирован (не разрешено)
- ❌ `RESTRICTED` - пользователь ограничен (не разрешено)

### Обработка ошибок:

Если при проверке возникает ошибка (например, бот не является администратором):
- Бот вернет `False` (пользователь считается неподписанным)
- В консоли будет выведено сообщение об ошибке
- Пользователь увидит предложение подписаться на канал

### Пример работы:

```
Пользователь: /start
Бот: "Чтобы я мог вам помочь, сначала подпишитесь на мой ТГ канал..."
     [Кнопка: Подписаться] [Кнопка: ✅ Я подписался]

Пользователь: [Нажимает "✅ Я подписался"]
Бот: Проверяет подписку...

Если подписан:
Бот: "Спасибо за подписку!"
     [Кнопка: Начать диалогику]

Если НЕ подписан:
Бот: "Пожалуйста, подпишитесь на канал, чтобы продолжить"
```

### Отладка:

Если проверка не работает:

1. Убедитесь что бот добавлен как администратор канала
2. Проверьте что `CHANNEL_USERNAME` в `.env` указан правильно (без @)
3. Проверьте логи бота на наличие ошибок
4. Убедитесь что канал публичный или бот имеет права администратора

### Код проверки:

Функция `check_channel_subscription()` находится в файле `bot.py`:

```python
async def check_channel_subscription(user_id: int) -> bool:
    channel = CHANNEL_USERNAME.lstrip('@')
    member = await bot.get_chat_member(f"@{channel}", user_id)
    return member.status in [
        ChatMemberStatus.MEMBER,
        ChatMemberStatus.ADMINISTRATOR,
        ChatMemberStatus.CREATOR
    ]
```
